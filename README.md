# AMDB Project Report

داشبورد و مرجع وضعیت پروژه «بانک اطلاعاتی فیلم افغانستان» (Afghanistan Movie Database — AMDB).

- وب‌سایت پروژه: https://amdb.af
- مخزن گزارش: https://github.com/armanaria111/amdb-report
- زبان‌های رابط: English (en)، دری (fa-AF)، پښتو (ps)
- فناوری اصلی پروژه: Laravel 13، PHP، MySQL

## فایل‌ها
- `index.html`: داشبورد گزارش پروژه
- `project-status.json`: داده‌های وضعیت، تصمیمات و سوابق ثبت‌شده
- `assets/style.css`: ظاهر داشبورد
- `assets/script.js`: بارگذاری داده‌ها و تعاملات داشبورد
- `CHANGELOG.md`: تاریخچه تغییرات گزارش

## به‌روزرسانی
با هر تصمیم یا پیشرفت تأییدشده در گفتگوهای AMDB، داده‌های `project-status.json` و در صورت نیاز تاریخچه تغییرات به‌روزرسانی می‌شوند.

> درصد پیشرفت کلی تا زمانی که کد و امکانات پروژه به‌صورت واقعی ممیزی نشده‌اند، اعلام نمی‌شود. مواردی که صرفاً نیازمندی یا تصمیم طراحی هستند، به‌عنوان قابلیت تکمیل‌شده نمایش داده نمی‌شوند.

## توجه درباره خصوصی بودن مخزن
این مخزن خصوصی است. داشبورد فایل استاتیک است و برای نمایش عمومی از طریق GitHub Pages باید تنظیمات Pages و دسترسی لازم جداگانه فراهم شود. داده‌های خصوصی را در فایل‌های عمومی یا توکن‌های سمت مرورگر قرار ندهید.
