## قواعد اعتماد به گزارش

1. فقط `current_status` در `project-status.json` مرجع آمار فعلی داشبورد است.
2. آمار فنی با تاریخ و commit مشخص ارائه می‌شود؛ تعداد فایل‌ها، تعداد جدول‌ها نیست.
3. وضعیت «پیاده‌سازی‌شده در سورس»، «تست موجود»، «تست اجراشده»، «Migration اجراشده» و «تأیید runtime/production» مستقل هستند.
4. تا زمان بررسی مستقیم دیتابیس، تعداد جدول‌های واقعی و Migrationهای اجراشده نامشخص‌اند.
5. گزارش‌های قدیمی و ممیزی‌های تاریخی برای حفظ سابقه نگهداری می‌شوند، اما وضعیت امروز محسوب نمی‌شوند.
6. درصد پیشرفت کلی محاسبه یا نمایش داده نمی‌شود.

## وضعیت قابلیت‌ها

اخبار و مقالات، جشنواره‌ها و جوایز، API عمومی v1، رسانه و اعلان‌ها و پیشنهاد اصلاح اطلاعات در main پیاده‌سازی شده‌اند؛ وضعیت آن‌ها «پیاده‌سازی‌شده در سورس، runtime تأییدنشده» است، نه «برنامه‌ریزی‌شده» و نه «تأییدشده عملیاتی». جزئیات و وضعیت همه قابلیت‌ها در داشبورد نمایش داده می‌شود.

## محدوده مخزن

این مخزن فقط برای مستندسازی، داشبورد و پیگیری وضعیت AMDB است. کد برنامه، Migrationها و داده‌های دیتابیس فقط در مخزن اصلی و محیط‌های مربوط مدیریت می‌شوند. هیچ عملیات مخرب دیتابیس مانند `migrate:fresh` یا `db:wipe` برای تهیه گزارش مجاز نیست.
