# AMDB Project Report

داشبورد و مرجع وضعیت پروژه «بانک اطلاعاتی فیلم افغانستان» (Afghanistan Movie Database — AMDB).

- وب‌سایت پروژه: https://amdb.af
- مخزن گزارش: https://github.com/armanaria111/amdb-report
- داشبورد زنده: https://armanaria111.github.io/amdb-report/
- فناوری ثبت‌شده: Laravel 13.39.0، PHP 8.5.12، MySQL
- محیط توسعه ثبت‌شده: Windows + Laragon
- زبان‌ها: English (en)، دری (fa-AF)، پښتو (ps)

## وضعیت دیتابیس بر اساس ممیزی گفتگو

در ممیزی گزارش‌شده در 2026-11-01، ساختار پروژه شامل **۴۲ جدول، ۲۵ مدل Eloquent، ۶۶ رابطه و ۲۷ مسیر** اعلام شده بود. همچنین ۱۰ migration در وضعیت `Ran` گزارش شده‌اند. حوزه‌های شناخته‌شده این migrationها شامل زبان‌ها، RBAC، پروفایل هنرمندان، `artist_id` و ترجمه‌ها است.

این اعداد، خروجی ممیزی در آن تاریخ هستند و نباید با درصد تکمیل محصول یا ممیزی مستقیم کد فعلی اشتباه گرفته شوند. نام کامل همه migrationها و فهرست دقیق تمام ۴۲ جدول در اطلاعات بازیابی‌شده از گفتگو موجود نبود؛ بنابراین در گزارش از ساختن نام‌های حدسی خودداری شده است.

## تصمیم‌های ثابت پروژه

- نام رسمی: بانک اطلاعاتی فیلم افغانستان / Afghanistan Movie Database / AMDB
- سه زبان: `en`، `fa-AF` و `ps`؛ دری و پشتو RTL هستند.
- سه پنل هدف: مدیریت، کاربر عادی و هنرمند/عوامل فیلم.
- کاربر عادی می‌تواند درخواست تأیید حرفه‌ای بدهد؛ ارتقای دسترسی پس از بررسی مدیر انجام می‌شود.
- هر حساب یک پروفایل هنرمند دارد و آن پروفایل می‌تواند چند حرفه هم‌زمان داشته باشد.
- شناسه‌های عمومی پایدار: هنرمندان `ar0000123`، آثار `am0000123` و شرکت‌ها `co0000123`.
- حفظ داده‌های موجود الزامی است؛ از `migrate:fresh`، `db:wipe` و migration مخرب استفاده نشود.

## آخرین وضعیت ثبت‌شده

در بررسی 2026-11-15، syntax فایل‌های `Artist.php` و `routes/web.php` و اجرای `optimize:clear` موفق گزارش شد. ۱۳ مسیر مرتبط با هنرمندان، مدیریت و ورود داده وجود داشت و مسیرهای عمومی `artists.index` و `artists.show` ثبت شده بودند.

موارد باز همان بررسی:
- URL هنرمند هنوز از شناسه داخلی `id` استفاده می‌کرد، نه `public_id`.
- مسیرهای claims وجود نداشتند.
- مجوز `settings.manage` وجود داشت و مدیر همه مجوزها را می‌گرفت، اما صفحه و امکانات تنظیمات هنوز ساخته نشده بود.
- دستور Tinker چندخطی با خطای parse مواجه می‌شد و دستور یک‌خطی جایگزین هنوز تأیید نشده بود.

## بخش‌های ناقص یا نیازمند تکمیل

- نقد و بررسی (reviews)
- گردش‌کار نظارت و مدیریت محتوا (moderation)
- پنل کامل هنرمند
- اخبار و جشنواره‌ها
- API
- پیشنهاد ویرایش اطلاعات (edit suggestions)
- تنظیمات سایت و مسیرهای claims
- تکمیل استفاده از public_id در URLها و شناسه‌های عمومی همه موجودیت‌ها
- فونت مستقل مناسب برای هر زبان، به‌ویژه پشتو

## فایل‌های مخزن

- `index.html`: داشبورد
- `project-status.json`: وضعیت ساختاریافته و تاریخچه پیشرفت
- `assets/style.css`: ظاهر داشبورد
- `assets/script.js`: بارگذاری و نمایش اطلاعات
- `CHANGELOG.md`: تاریخچه تغییرات گزارش

## روش ثبت وضعیت

با هر پیشرفت تأییدشده، `project-status.json` و `CHANGELOG.md` به‌روزرسانی می‌شوند. وضعیت‌های «گزارش‌شده» از موارد «ناقص» و «برنامه‌ریزی‌شده» جدا هستند. درصد پیشرفت کلی تا زمان ممیزی مستقیم کد و دیتابیس تعیین نمی‌شود.
